# 第 03 次课教师指南｜P1 v1.2.0 数据化

## 本课完成结果

项目内容不再重复写死在 HTML 中。学生用数组保存项目对象，用循环创建页面卡片，并能解释“输入数据—规范化处理—DOM 输出”的完整路径。

## 课前教师演练

```powershell
git switch p1-v1.1
npm ci
npm test
npm run build
git switch main
```

确认 v1.1 可恢复后，比较 `index.html`、`data.js`、`app.js` 和 `scripts/project-service.mjs`。

## 20 分钟演示脚本

1. 先在 Console 建一个只含姓名的对象，读取属性。
2. 把三个项目写成数组，使用 `for...of` 输出名称。
3. 从 HTML 删除写死的项目卡，保留 `project-list` 容器。
4. 使用 `textContent` 创建标题和简介，解释为何不直接拼接不可信 HTML。
5. 把项目数组改为空，观察空状态和项目数量。
6. 删除某个项目的名称或写入本机路径，运行测试观察默认值和拦截结果。

## 三类测试

| 类型 | 输入 | 预期结果 |
| --- | --- | --- |
| 正常 | 三条完整项目数据 | 显示三张卡和数量 3 |
| 边界 | 空数组 | 显示空状态和数量 0 |
| 失败 | 缺少名称、本机 URL | 使用默认名称且不生成危险链接 |
