# 第 02 次课教师指南｜P1 v1.1 可投递履历

## 本课完成结果

学生在上一课固定 URL 上发布响应式履历：手机单列、桌面双列、打印稿去除装饰并显示链接地址。课程结束前必须完成自动检查和三种视图证据。

## 课前教师演练

```powershell
git switch p1-v1.0.1
npm ci
npm test
npm run build
git switch main
```

确认旧版本可恢复，再打开主分支演示 v1.1。不要在课堂上从最终 CSS 开始讲，先让窄屏内容保持单列，再添加桌面断点和打印规则。

## 20 分钟演示脚本

1. 用 DevTools 将视口切为 390px，确认阅读顺序。
2. 添加 `@media (min-width: 700px)`，让主要内容变为两列。
3. 给关于我和项目卡添加 `wide-card`，演示跨越两列。
4. 打开打印预览，观察背景、阴影和链接信息。
5. 用 Tab 键从“跳到主要内容”开始依次访问链接。
6. 删除 `@media print` 后运行 `npm run check`，展示 CI 如何阻止不符合要求的版本。

## 学生当堂测试

| 类型 | 操作 | 预期结果 |
| --- | --- | --- |
| 正常 | 1440px 桌面查看 | 内容为两列，宽卡跨两列 |
| 边界 | 320px、200% 缩放 | 无横向滚动，文字不被遮挡 |
| 失败 | 禁用 CSS 或删除一张卡片内容 | HTML 阅读顺序仍合理 |
| 打印 | 打开打印预览 | 无背景阴影，卡片不跨页断开 |
| 键盘 | 只使用 Tab | 焦点清晰，可跳到主要内容 |
