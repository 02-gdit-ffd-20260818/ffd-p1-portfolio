# 第 04 次课教师指南｜P1 v1.2.1 筛选排序

## 本课完成结果

学生使用纯函数完成项目筛选、排序和技能去重，并将数据、业务逻辑、DOM 渲染分离。反复切换筛选后原项目数组必须保持不变。

## 课前教师演练

```powershell
git switch p1-v1.2.0
npm ci
npm test
git switch main
npm test
npm run build
```

重点查看 `scripts/project-service.mjs` 的前后变化，而不是先看界面。

## 20 分钟演示脚本

1. 在 Console 对同一数组直接使用 `sort`，观察原顺序被修改。
2. 改为 `[...items].sort(...)`，再次检查原数组。
3. 用 `filterProjects` 分别传入 `all`、`API` 和不存在的技能。
4. 用 `Set` 收集不重复技能，动态生成下拉选项。
5. 连接两个 `change` 事件，每次都从 `allProjects` 重新计算。
6. 故意删掉数组复制，运行测试展示失败。

## 三类测试

| 类型 | 操作 | 预期结果 |
| --- | --- | --- |
| 正常 | 选择 JavaScript | 只显示匹配项目 |
| 边界 | 选择全部并连续切换升降序 | 项目不丢失，原数据不变 |
| 失败 | 传入不存在的技能 | 显示空状态，不报错 |

## 收尾证据

- 12 个累计自动测试；
